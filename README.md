
This is the source code to the deployed NC Scratchers web app [hosted here](https://marcoshuerta.com/dash/nc_scratchers/).

The file `nc_scratchers.py` builds the database, and the Dash app `app.py` reads that database and shows the latest info on the best expectation value cars.

See the `about.md` file for more details, adapted from the information on my [similar but older site for Virginia scratch-offs](https://marcoshuerta.com/scratch_to_win/).

Once I have more time series data, I will build some plots into the details pages in the web app.
